Política de privacidad

Vigente desde el 20 de noviembre de 2026.

1. Quién usa la aplicación

IG Trial Reels Manager es una herramienta personal de escritorio. La usa únicamente su titular, con su propia cuenta de TikTok (@aleretaa) y su propia cuenta de Instagram (@alejoretamar_). No ofrece cuentas ni servicios a terceros.

2. Datos de TikTok que se usan

Con la autorización que el titular otorga en la pantalla oficial de TikTok, la aplicación usa la Display API con estos permisos, solo de lectura:

PermisoDatosUso
user.info.basicIdentificador de la cuenta y nombre visibleMostrar qué cuenta se conectó. No se guardan.
video.listDe cada video público propio: identificador, fecha de publicación, título, descripción, enlace, duración, dimensiones, cantidad de vistas y de me gusta, y la dirección temporal de la portadaCompletar la biblioteca personal: vincular cada video con su registro, conservar la descripción y los hashtags originales y mostrar su enlace

Además, la aplicación puede leer:

  • El archivo de exportación oficial de datos que el titular descarga de su cuenta de TikTok. Solo se incorporan sus videos públicos. De las fotos y las publicaciones privadas que figuran en ese archivo se conserva únicamente la fecha, para no confundirlas con videos públicos; no se descargan ni se catalogan.
  • Los archivos de video de sus propias publicaciones, mediante los enlaces temporales que trae esa misma exportación, solo para los videos que el titular elige conservar.
  • La página pública de un video propio, cuando el titular decide recuperar ese video en particular. Para esto usa yt-dlp, una herramienta de código abierto que no es una API oficial de TikTok: lee los datos públicos del video y su archivo sin marca de agua, sin iniciar sesión ni usar cookies. No se usa para recorrer el perfil completo.

La aplicación no publica ni modifica nada en TikTok y no accede a datos de otras cuentas.

3. Datos de Instagram

Para publicar, la aplicación usa la API oficial de Meta con el token de la cuenta de Instagram del titular. Solo publica los videos que el titular aprueba, como Trial Reels. Después lee el estado de la publicación, su enlace y sus estadísticas.

Para que Instagram pueda tomar el archivo, la aplicación lo expone por un enlace temporal y aleatorio de Cloudflare (Quick Tunnel). Ese enlace sirve un único archivo y se cierra al terminar la publicación.

4. Dónde se guardan los datos

  • Toda la información (base de datos, videos, miniaturas y registros) se guarda en la computadora del titular. La aplicación no tiene servidores propios.
  • Los tokens de TikTok e Instagram se guardan en un archivo local de configuración, con permisos de lectura solo para el usuario del equipo. El token de acceso de TikTok se usa en memoria durante cada operación; se guarda únicamente el token de renovación.
  • Los registros de actividad de la aplicación ocultan los tokens y las direcciones firmadas.

5. Con quién se comparten

  • TikTok y Meta (Instagram): los intercambios necesarios con sus API oficiales y, en el caso de TikTok, la lectura de las páginas públicas de videos propios descripta arriba.
  • Cloudflare: transporta el archivo de video hacia Meta durante una publicación.
  • No se venden ni se ceden datos a nadie más. No hay publicidad, cookies, analítica ni seguimiento.

6. Este sitio web

Estas páginas son estáticas y se alojan en GitHub Pages. No usan cookies ni scripts. GitHub puede registrar datos técnicos de las visitas, como la dirección IP, según su propia declaración de privacidad.

7. Cómo revocar la autorización y borrar los datos

  • En TikTok: el titular puede quitar el acceso de la aplicación desde la sección de permisos de aplicaciones de la configuración de su cuenta de TikTok. Desde ese momento la aplicación ya no puede leer su lista de videos.
  • En la aplicación: borrar el token de renovación del archivo de configuración local desconecta la cuenta.
  • Datos locales: como todo se guarda en la computadora del titular, se eliminan borrando la carpeta de datos de la aplicación.
  • En Instagram: el acceso se revoca desde la configuración de integraciones de Meta.

8. Menores

La aplicación no está dirigida a menores y no recopila datos de otras personas.

9. Cambios

Si cambia el funcionamiento de la aplicación, esta política se actualizará en esta misma página, con su nueva fecha de vigencia.

10. Contacto

Las consultas sobre esta política se reciben en la sección Issues del repositorio público de estas páginas. Ese canal es público: no incluyas datos personales en tu mensaje.

English summary

IG Trial Reels Manager is a personal desktop tool used only by its owner (TikTok @aleretaa, Instagram @alejoretamar_). With the owner's authorization on TikTok's consent screen, it uses the Display API scopes user.info.basic (account identifier and display name, shown but not stored) and video.list (the owner's own public videos: ID, posting date, title, description, link, duration, size, view and like counts, temporary cover URL) to organize the owner's video library. It also reads the owner's official TikTok data export (only public videos are catalogued; for photos and private posts only their date is kept, to tell them apart), may download the files of videos the owner chooses through that export's temporary links, and, for an individual own public video, may use the open-source tool yt-dlp (not an official TikTok API; no login, no cookies, not used to crawl the profile). It never posts to TikTok and never accesses other users' data.

All data is stored locally on the owner's computer; there are no servers. Tokens are stored in a local configuration file readable only by the computer's user, and activity logs hide tokens and signed URLs. Data is exchanged only with TikTok and Meta through their official APIs, and with Cloudflare, which carries the video file to Meta during a publication through a temporary random link that is closed afterwards. No data is sold or shared; no ads, cookies, analytics or tracking. Access can be revoked at any time in TikTok's app-permission settings, by deleting the local refresh token, or by deleting the app's local data folder. Contact: Issues section of this site's public repository (public channel: please do not include personal data).
